## 🚀 Instalasi

### Prerequisites
- Node.js 16.0.0 atau lebih baru
- npm atau yarn
- WhatsApp Web access

### Langkah Instalasi

1. **Clone repository**
```bash
git clone https://github.com/yourusername/whatsapp-super-bot.git
cd whatsapp-super-bot
```

2. **Install dependencies**
```bash
npm install
```

3. **Jalankan bot**
```bash
npm start
```

4. **Scan QR Code**
- Buka WhatsApp di HP
- Scan QR code yang muncul di terminal
- Bot siap digunakan!

### Command Dasar
```
/help - Daftar semua command
```

## 🌐 Dashboard Web

Bot ini dilengkapi dengan dashboard web real-time yang dapat diakses di `http://localhost:3000`

### Fitur Dashboard
- 📊 **Real-time Statistics** - Grafik aktivitas grup
- 🏆 **Member Leaderboard** - Ranking member terbaik
- 🎮 **Game Statistics** - Statistik permainan
- ☁️ **Word Cloud** - Visualisasi kata populer
- ⚙️ **Bot Controls** - Start/stop bot, edit responses
- 📈 **Analytics Dashboard** - Insight mendalam tentang grup
- 🔧 **Settings Panel** - Konfigurasi fitur bot

### API Endpoints
- `GET /api/stats` - Statistik grup
- `GET /api/leaderboard` - Leaderboard member
- `GET /api/wordcloud` - Word cloud data
- `GET /api/bot/status` - Status bot
- `POST /api/bot/maintenance` - Maintenance mode
- `GET /api/commands` - Daftar command

## 🚀 Deployment

### Local Development
```bash
npm run dev
```

### Production (cPanel)
1. Upload semua file ke hosting
2. Install dependencies: `npm install --production`
3. Set environment variables
4. Start bot: `npm start`

### Environment Variables
```env
PORT=3000
NODE_ENV=production
```

### PM2 (Recommended)
```bash
npm install -g pm2
pm2 start app.js --name whatsapp-bot
pm2 save
pm2 startup
```
